# Needle Hold Angle の測り方

EASE の Needle Hold Angle（Needle tip to Driver angle）を、セグメンテーション（Astra のポリゴン）と event から測る。
EASE には本文の定義がないため、図の矢印（どちらも持つ点から出る）に従い、次の角とする。

> 持つ点から針先の端への向きと、持つ点から器具の根元へ向かう向きのなす角（0〜180 度）

180 度は針が器具の延長線上の前方に伸びる（flush）、90 度は真横、90 度未満は根元側（acute）。
EASE の基準は 90〜135 度が理想、135〜150 度が adequate、それ以外が不合格。

## 区間

1. 持つ区間: その針の刺入（needle_entry）の直前の needle_reposition_end から刺入まで。
   なければ前の needle_withdrawal_end（1 針目は動画の最初）から
2. 最後に持ち続けた区間: 刺入から時間をさかのぼり、同じ器具が針を持ち続けている間（1 秒以内の途切れは許す）
3. その中の、刺入の直前 2 秒のフレーム（10 fps、約 20 枚）。1 針の値は、これらのフレームの角度の中央値

刺入の直前に限るのは、画面上の角度が手首の回転で変わるため。持ち直した直後は針が器具の延長線上に見えることが多く、
刺すために構えた後の角度が EASE の「針を持ったときの角度」に当たる。

## フレームごとの計算

1. 持つ器具と持つ点: 器具のポリゴンを 3 画素膨らませ、針のポリゴン（全片）と重なる器具が 1 本のとき、その器具を持つ器具とし、
   重なる画素の重心を持つ点とする
2. 顎の両側の針の片: 持つ器具から 6 画素以内にある針の片。片ごとに、持つ点から最も遠い点をその片の端とする
3. 器具の根元の向き: 持つ器具のポリゴン全体の主軸を、器具の重心の側に向けたもの
4. 針先の片:
   - 刺入の後 0.3〜1.5 秒のフレームで、片の長さがどれだけ残るかを見る。最も短くなる片（組織に入る片）を、刺入の直前の針先の片とする。
     刺入の前後の片は、器具の根元の向きから見た片の端の向き（60 度以内）で対応づける
   - そこから 1 フレームずつ時間をさかのぼり、直前のフレームの針先の端に最も近い端（40 画素以内）を針先の端とする
5. 角度: 持つ点から針先の端への向きと、器具の根元の向きのなす角

## パラメータ

| 値 | 意味 |
|---|---|
| 3 画素 | 針と器具が接しているとみなす距離 |
| 6 画素 | 顎の両側の片とみなす、持つ器具からの距離 |
| 1 秒 | 最後に持ち続けた区間で許す途切れ |
| 0.3〜1.5 秒、60 度 | 刺入の後に短くなる片を見る範囲と、片の対応づけ |
| 40 画素 | 0.1 秒で針先の端が動く上限 |
| 2 秒 | 角度を見る、刺入の直前の長さ |

## 開発データでの結果

B・E の 7 本 28 針（持つ区間は正解の event）で、EASE の点数との順位相関 −0.50。
EASE の基準そのまま（90〜135 度なら理想）で 28 針中 23 針が点数（理想 / それ以外）と一致。
点数は B が全針 1、E が全針 3。
