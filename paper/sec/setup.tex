\subsection{Data and annotations}
\label{ssec:data}

We use the JIGSAWS suturing task~\cite{Gao2014}, comprising 39 bench-top
robotic suturing trials of four stitches each, performed by eight surgeons
with self-reported skill levels ranging from novice to expert. To support
applicability to video-only settings, we use only monocular endoscopic video
(capture1), excluding stereo video and robot kinematics.

To prevent data leakage, surgeons are split into development (four trials each, 64 stitches)
and test sets (all 19 trials, 76 stitches), each with one expert, one
intermediate, and two novices. All design choices, few-shot examples,
and parameters are fixed on the development set before a single test
evaluation. A physician annotated events and EASE scores~\cite{Haque2022} for every
stitch using only the capture1 video.

\subsection{Implementation}
\label{ssec:implementation}

Events, keypoints, and needle masks are generated using GPT-6
Astra~\cite{OpenAI2026Astra} (\texttt{gpt-6-astra}, medium reasoning
effort), a general-purpose VLM accessed via the OpenAI API without weight
updates. Each request includes definitions, few-shot examples, and target
frames and yields structured outputs. Examples come from two extra trials by
development-set surgeons, used only for prompting, not method development or
testing.

For events, example frames around each event type come from one of these
trials; detection uses 5 fps, 20 s requests, 10 s context on each side
(excluded from detection), and previously detected events. For keypoints and
masks, 20 annotated frames from the other trial serve as examples; processing
uses 10 fps and 20-frame requests, returning polygon masks.
Via the OpenAI Batch API, the whole pipeline cost about US\$11 per trial of
about two minutes; a locally trained perception model would remove this cost.

\subsection{Baselines and metrics}
\label{ssec:metrics}

The baseline is given favorable conditions: the same VLM receives
human-annotated assessment windows and three scored development stitches as
examples, with EASE criteria and quantity definitions. It scores the three hold
sub-skills from frames at 5 fps with 10 s of context on either side,
returning a score, per-score probabilities, and quantity estimates.

We evaluate two settings: annotated-window scoring, isolated from event
detection and compared with the baseline on identical stitches; and
end-to-end detection and scoring of all four sub-skills. Each annotated stitch
is matched one-to-one to the detected stitch with the nearest entry within
it. Event detection is evaluated by F1 with a 1-s tolerance over the four event
types.

We report AUC for distinguishing the best EASE score (3; 2--3 for Needle
Hold Ratio) from others, as in~\cite{Deo2026}, and balanced accuracy averaged
over observed score classes. For AUC, our method ranks stitches by the signed
margin to the best-score criterion (e.g.,
$\min(\alpha_i-90^\circ,135^\circ-\alpha_i)$ for angle), and the baseline by
its best-score probability; its quantity estimates are ranked by the same
margin. Unscorable stitches count as errors in both metrics (none occurred).
We obtain 95\% confidence intervals by video-level bootstrapping for
correlated stitches, using paired resampling for method
differences.
